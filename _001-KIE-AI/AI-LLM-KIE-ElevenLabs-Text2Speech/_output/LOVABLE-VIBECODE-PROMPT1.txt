Step 2. Core Product Loop
-----------------------------------------------------------------------------------
I want the user to see a special area where they can upload their P&L (to the left), and a preview of the metrics that will be generated based on their P&L including Revenue Growth, Net Margin, Gross Margin, Net Burn. This should be designed in a way so that the user is encouraged to put in the inputs so they can get their personalized version of the outputs.

Once the inputs have been entered, there should be a button to process the inputs and generate the personalized outputs. There should be a nicely designed waiting indicator so that the user does not get bored while the data is processed.

Once uploaded, use AI to extract and analyze real data from the P&L statement in the PDF file.

Once the data is processed, the user should be able to see their personalized data based on their inputs. The input area can be minimized with a refresh button to put in new data and the outputs and personalized report can be shown so that the user can focus on it.

Step 4. Conversion
-------------------------------------------------------------------------------------
I want to add an advanced paid feature. I want an AI CFO to analyze the P&L and write a full 6-page Amazon-style memo about the trends, opportunities, strengths, weaknesses and risks around the business. Show beautiful progress indicators so the user doesn’t get bored while the AI analyzes the data and writes the report. I want this memo to be visible in a very beautiful way so that the user can fully understand the story around their uploaded P&L. Make sure paragraphs and bullet points and sections are shown cleanly so it is easy to consume and read.

I want this in-depth report to be a gated feature. So show user affordance about getting the detailed report, when clicked, show a modal with the benefits of the feature, and that the user has to convert to a paid account paying $99/year to view it. When the user hits the button to sign up, take them to the sign up form, collect their name, email and set up their account in the backend and start a 7-day trial (no need to integrate Stripe for now). Log them in, and then show them their analysis.

Once a user is logged in, show a sticky header for the application with relevant links.
